# Labs

Hands-on lab assignments that reinforce the modules. Each lab follows the same pattern:

- `lab-XX-name/README.md` - the brief: task, starter hints, expected output, and self-check questions.
- `lab-XX-name/starter.R` - code skeleton with `# TODO` markers for you to complete.
- `lab-XX-name/solution.R` - the worked solution; open it only after your own attempt.

Labs are self-graded: compare your output against the expected output listed in the lab brief. There is no submission step - what matters is that your script runs and produces the same result. Record completion by ticking the related module in `PROGRESS.md`.

Labs are added progressively as module content is written; until then this folder intentionally contains only this index.
