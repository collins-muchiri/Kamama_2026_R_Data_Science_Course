# Assessments

Checks for understanding, organized to match the modules:

- **Quizzes** - short multiple-choice checks (5-10 questions) at the end of each module, with an answer key kept in a separate `answers/` subfolder so you can self-test first.
- **Coding challenges** - small problems solved in a single R script; graded against explicit acceptance criteria (does it run, is output correct, is the code readable).
- **Assignments** - larger graded tasks (per phase) with a published rubric covering correctness, code style, reproducibility and clarity of interpretation.

## Grading rubric (assignments)

| Criterion | Weight | What full marks looks like |
| --- | --- | --- |
| Correctness | 40% | Runs without errors; results match the expected output |
| Code quality | 25% | Clear names, functions reused sensibly, no copy-paste blocks |
| Reproducibility | 20% | Works from a fresh session using relative paths and a setup chunk |
| Interpretation | 15% | Findings explained in plain language, not just printed numbers |

Self-assessment first, then check against solutions. Everything in this folder is graded by you, for you - the goal is honest feedback on where you stand.
