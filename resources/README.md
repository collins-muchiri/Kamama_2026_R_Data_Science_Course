# Resources

Reference material to keep you fast while you learn:

- **Cheatsheets** - one-page summaries of the most-used syntax (base R types, dplyr verbs, ggplot2 layers, tidyr pivots). Official Posit cheatsheets: https://posit.co/resources/cheatsheets/
- **Style guide** - the tidyverse style guide the course follows for names and formatting: https://style.tidyverse.org/
- **Documentation** - canonical package docs: https://www.rdocumentation.org/
- **Community help** - how to ask a good question: https://stackoverflow.com/questions/tagged/r

Rule of thumb: official documentation first, then a targeted search, then - only if stuck for more than 30 minutes - ask a community with a minimal reproducible example.
