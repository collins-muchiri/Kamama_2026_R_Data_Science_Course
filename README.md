# Kamama_2026_R_Data_Science_Course

A self-contained, open-source R data science course: from zero R to job-ready in 12-16 weeks, with hands-on labs, quizzes, and a portfolio capstone project.

## Project Description

This repository is a complete, standalone curriculum for learning R and modern data science with the tidyverse. Everything needed to run the course lives in this repo: numbered lessons, runnable code examples, exercises with solutions, quizzes, graded assignments with rubrics, openly licensed datasets, and a final capstone project suitable for a professional portfolio. No paid platforms or external LMS are required - only R, RStudio, and the files in this repository.

## Purpose

- Learn R from first principles: installation, syntax, data types, vectors, factors, dates, functions, control flow, and debugging.
- Master the modern data science workflow: importing, cleaning, reshaping, exploratory data analysis, and visualization with ggplot2.
- Apply statistics and machine learning: correlation, regression, classification, clustering, prediction, and model evaluation.
- Build professional habits: reproducible reporting with R Markdown, Git and GitHub workflows, automation, and clean project structure.

## How to Use

### Prerequisites

1. Install R (version 4.3 or newer): https://cran.r-project.org/
2. Install RStudio Desktop (free): https://posit.co/download/rstudio-desktop/
3. Optional: a GitHub account, needed for the version control modules and for publishing your own capstone portfolio.

### Quick Start

```bash
git clone https://github.com/collins-muchiri/Kamama_2026_R_Data_Science_Course.git
cd Kamama_2026_R_Data_Science_Course
```

1. Open the cloned folder in RStudio (File > Open Project).
2. Start with `modules/00_getting_started/` and follow the modules in numeric order.
3. For each module, follow the fixed sequence: read the lesson, run the examples, complete the exercises, then compare against the provided solutions.
4. Track your progress in `PROGRESS.md` and finish with the capstone in `projects/capstone/`.

## Suggested Pace

12-16 weeks at roughly 8-10 hours per week. Modules are sequenced from foundations to advanced machine learning; each module states its estimated hours, learning objectives, required versus optional content, and prerequisites.
