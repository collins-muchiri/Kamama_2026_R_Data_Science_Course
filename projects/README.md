# Projects

Portfolio-level work. Two kinds of projects live here:

## Mini-Projects (one per course phase)

Short, focused builds (1-2 days each) that consolidate a phase:

1. **Phase 1:** a well-organized multi-function script that processes a small text/data file.
2. **Phase 2:** an end-to-end EDA report (import, clean, visualize, summarize) rendered with R Markdown.
3. **Phase 3:** an automated pipeline that pulls data, trains a model and renders a parameterized report.

## Capstone Project (Weeks 14-16)

The final deliverable of the course, designed to be portfolio-grade:

- A real, openly licensed dataset of your choice (see `data/README.md` for source policy).
- A clearly stated question, a reproducible pipeline, at least one model with honest evaluation, and a written report a non-technical reader can follow.
- Published to **your own** GitHub repository so it becomes part of your professional portfolio.

The full capstone brief (requirements, rubric and submission checklist) is added to `projects/capstone/` when the Phase 4 content is written. Until then, use the milestones in `PROGRESS.md` to gauge readiness.
